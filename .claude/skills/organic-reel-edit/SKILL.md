# organic-reel-edit

## Estilo (fuente: STYLE_DECISIONS §A y §G)
- Vlog documental, crudo pero cuidado. Paleta de azules/agua; gradación natural.
- Subtítulos palabra por palabra, dinámicos.
- Contenido inmobiliario solo como Reel colaborativo con propiedades top. **No convertir OLY en catálogo.**

## Proceso
1. Hacer ingest y proxy (igual que en property-reel, paso 1).
2. Transcribir y proponer cortes de silencios y repeticiones (Auto-Editor). Mantener el contexto natural.
3. Elegir un gancho a partir de lo que Nixon realmente dijo o hizo. Preparar 3 variantes A/B/C solo para los 0–3 s y la portada.
4. Render a 1080×1920, más portada 4:5 y copy corto para IG, más una versión para Facebook personal si aplica.
5. Ejecutar `prepublish-qa`.

## Prohibido
Datos de clientes en pantalla. Menores sin consentimiento. Música sin licencia libre registrada. Inventar logros o resultados.
